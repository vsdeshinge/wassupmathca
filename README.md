# Wassup Matcha — media-led concept build

Next.js + Tailwind CSS + Motion concept for Wassup Matcha.

This iteration keeps the full-video hero and rebuilds the rest of the page as media-led storytelling rather than flat colour sections.

## Included
- Full-screen video hero
- Animated rain / condensation layers
- Media moodboard section
- Full-bleed Rain and Matcha manifesto films
- Interactive rain-window reveal
- Interactive menu media
- Full-screen signature drink stories
- Sticky founder-story film
- Video-led community/events section + moving gallery strip
- Full-screen visit/location ending
- Desktop cursor image motion + mobile-specific motion treatment
- Brand font hooks for NF-Le Petit Cochon and Pencilant

## Brand fonts
Place licensed font files here:

- `public/fonts/nf-le-petit-cochon.ttf`
- `public/fonts/pencilant-script.ttf`

## Run
```bash
npm install
npm run dev
```

Dummy remote imagery/video is for visual direction only and should be replaced with the final Wassup Matcha shoot.
